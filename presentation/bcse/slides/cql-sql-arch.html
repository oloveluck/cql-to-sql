Method B computes the same measure inside a database. Two things meet there. The rules: a translator rewrites each of NCQA's rules as a step of one SQL query. The records: standard definitions flatten the FHIR health records into ordinary tables, with checks that nothing is lost. The database answers the checks for every member at once, which scales to millions. The result is the same standard report, so we can compare it with Method A member by member.
