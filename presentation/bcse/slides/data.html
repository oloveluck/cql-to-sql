Three kinds of test. The 19 hand-built members check the logic path by path. The first 1,000-member population is written the way clinical systems hold records, and comes with an answer key from its author: an independent second opinion. The second 1,000 is written the way health plans report to NCQA, from insurance claims. All the data is synthetic, and all of it uses NCQA's real 2025 code lists.
